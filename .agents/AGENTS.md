# MYBIRKIN 项目上下文

## 项目概览
- 高端手工皮具电商网站
- 域名: mybirkin.com
- 技术栈: Next.js 14 + TypeScript + Tailwind CSS
- 部署目标: Vercel (免费) + Supabase (数据库)
- 项目路径: /Users/zhanghaotian/Documents/Codex/2026-07-26/new-chat/myshop

## 已完成功能
1. 品牌色调: paper/ivory/charcoal/gold 高级配色，对标 Hermès/The Row
2. 首页: Hero 大图 + 新品 + 精选 + 三分区 + 品牌承诺
3. 商品系统: 列表页 + 详情页(轮播/颜色/规格)
4. 购物车: Context 状态管理 + 侧边抽屉
5. 结账: 地址表单 + 订单摘要 (Stripe预留)
6. 工艺展示: /craft (皮料/五金/工匠/制作流程)
7. 客户评论: 每产品页底部，localStorage存储
8. 定制 Builder: Hermès皮料体系 + 双色拼接 + 五金/款型/工匠
9. 管理后台: /admin (产品CRUD + Builder数据 + 首页编辑 + 联系方式)
10. 悬浮客服: WhatsApp/Telegram可配置
11. 数据存储: localStorage (待迁移到Supabase)
